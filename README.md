# hammerspoon

Personal macOS automation config

## Spoons

### WM - Window Manager

Keyboard window management. Requires [Karabiner-Elements](https://karabiner-elements.pqrs.org/) to map caps lock -> hyper (`ctrl+alt+cmd+shift`).

All bindings and layouts are configured in `Spoons/WM.spoon/config.lua`.

#### Bindings

| Key        | Action           |
|------------|------------------|
| hyper+T    | Terminal         |
| hyper+E    | Editor           |
| hyper+B    | Browser          |
| hyper+=    | New tab          |
| hyper+H    | Snap left        |
| hyper+L    | Snap right       |
| hyper+K    | Snap top         |
| hyper+J    | Snap bottom      |
| hyper+F    | Fullscreen       |
| hyper+C    | Center           |
| hyper+Z    | Undo move        |
| hyper+N    | Next monitor     |
| hyper+P    | Prev monitor     |
| hyper+tab  | Focus next screen|
| hyper+`    | Cycle windows    |
| hyper+R    | Resize mode      |
| hyper+D    | Dev layout       |
| hyper+M    | Laptop layout    |
| hyper+\    | Help             |
